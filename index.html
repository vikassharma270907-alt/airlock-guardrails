Grounded in Empirical Research

Airlock translates findings from software engineering and agent security studies into deterministic code. Citations were not independently verified in full; see each paper.

arXiv 2605.07062

From Assistance to Agency: Rethinking Autonomy and Control in CI/CD

Studies emphasize that agentic CI/CD deployments require strict external governance over control-plane actions rather than unverified autonomous delegation.

Airlock Guardrail: policy_gate.py blocks all edits to CI/CD pipelines, tools, and test suites.
GitLab Docs & arXiv 2606.09935

Security Threats in Agentic Systems & GitInject

Untrusted issue descriptions and pull request comments can introduce indirect prompt injection risks when connected to active agent tooling.

Airlock Guardrail: Dual-agent reader/writer split ensures untrusted text never reaches active tools.
arXiv 2603.06858

Patch Validation in Automated Vulnerability Repair

Empirical evaluations show that automated patches passing unit tests may still fail exploit testing, making independent security re-scanning necessary.

Airlock Guardrail: sast_gate.py requires clean re-scans, halting MRs on High/Critical findings.
arXiv 2510.22075

Bounded Repair Iteration Budgets

Research supports enforcing bounded iterations (capping automated fix attempts at 3) to maintain pipeline stability before escalating to human engineers.

Airlock Guardrail: Fix Pipeline flow enforced with a strict 3-attempt ceiling before human escalation.
